# نسخة Android التجريبية للواجهة

هذا الفرع لتجربة الواجهة العربية الجديدة داخل لوحة التطبيق، وليس إصدارًا للنشر العام. لم تتغير محركات الألعاب أو القصص أو مفاتيح التقدم. وهو مستقل عن إصدار الموقع المنشور.

## فصل النسخة التجريبية

- تُبنى نسخة `debug` بالمعرّف `com.kokabfodool.offline.trial` وباسم «كوكب فضول - تجربة»، حتى تُثبّت بجانب التطبيق الأصلي دون استبداله. بياناتها المحلية منفصلة ولا تنسخ تقدم التطبيق الأصلي تلقائيًا.
- يُعطَّل إعداد النسخ السحابي داخل أصول نسخة `debug` فقط، حتى لا تتصل هذه النسخة التجريبية بمشروع النسخ الاحتياطي الفعلي. لا يتغير الإعداد الأصلي في الشجرة أو في إصدار `release`.
- تستخدم `debug` توقيع تطوير محليًا؛ لا تُرفع هذه الحزمة إلى Google Play، ولا يُستبدل بها ملف التنزيل المستقر على الموقع. لا يُنقل توقيع التطوير إلى المستودع.
- قبل إعداد إصدار فعلي لاحقًا، يجب مراجعة شهادة التطبيق ومفتاح الرفع، ورفع `versionCode` بما يناسب الإصدارات المنشورة، وتحديث اختبارات الإصدار، وإجراء اختبار ترقية حقيقي يحافظ على بيانات المستخدم. لا يُدمج إعداد `debug` التجريبي باعتباره إصدارًا جاهزًا للنشر.

## البناء والاختبارات

تحتاج Java 17 وGradle 8.13 وAndroid SDK platform 36 وأدوات البناء المناسبة:

```sh
gradle -p android-app --no-daemon assembleDebug
python3 scripts/verify-v5.py
python3 scripts/verify-seo.py
python3 scripts/verify-learning-presence.py
# بعد تثبيت Playwright وChromium:
CHROMIUM_PATH=/usr/bin/chromium node scripts/test-manus-app-dashboard.cjs
```

يفحص اختبار المتصفح أحجام الهاتف والحاسب، والتنقل إلى لعبة وقصة، وبقاء قيم تقدم اختبارية بعد التنقل، وتحديث الحزمة والعودة دون اتصال. لا يحلّ فحص المتصفح محل اختبار Android حقيقي أو اختبار ترقية تطبيق فعلي. في PWA، من يستخدم حزمة قديمة يحتاج تحديثها أثناء الاتصال لظهور النمط الجديد دون اتصال؛ غلاف PWA الصغير وحده يعود إلى الأنماط السابقة إذا لم تتوفر الحزمة الكاملة.
