# Kawkab Fudool V5.0 — release baseline
Date: 2026-11-15 (UAE). Development branch: v5-education-platform. Production: main, GitHub Pages, https://kokabfodool.com. No DNS change.
## Scope
V5 evolves existing V4.1 source, not a rewrite. Five independent views: home, learn, games, achievements, more. Arabic + English. Original character assets (Lumaa, Mishaal, Robo, brand and hero artwork). Eight series, 54 indexed episodes in each language; each episode uses the existing site route. Existing 20 bilingual games, levels, progress/profile storage keys, audio and original visual assets retained. Online reads the site's current content; Offline bundles local library artwork, games and audio; actual video watching needs internet. External links are guarded by parent confirmation.

## Release and publication sequence
1. Confirm the stable signing secret is present. Rerun Android workflow from the current v5-education-platform HEAD; without the secret the build is preview-only.
2. The workflow verifies the certificate, builds both editions and runs the browser test before staging files. Stage job publishes nothing to main: it commits the signed APKs and release.json to the development branch.
3. Verify both filenames, hashes, exact sizes, version and public certificate in downloads/apps/release.json. Test installation and offline games on Android; check YouTube/Instagram/website links.
4. Merge the prepared release PR into main only after checks. Verify https://kokabfodool.com/app/ and /en/app/, both APK download links and site navigation; retain existing hosting/domain.
5. After successful deployment, create an immutable release reference for the final commit and keep main as the base for the next branch. Increment versionCode/versionName and preserve the signing identity and application IDs for V5.1 and later.
