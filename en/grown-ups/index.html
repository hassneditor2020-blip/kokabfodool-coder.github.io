Practice ideas

At home

Start with one sheet. Say the letter or number together and trace it with a finger before using a pencil.

In the classroom

Print a set and choose a sheet for each learner. Use classroom objects to show each quantity.

For review

Ask the child to name another word that begins with the letter or arrange the same number of objects in two ways.
