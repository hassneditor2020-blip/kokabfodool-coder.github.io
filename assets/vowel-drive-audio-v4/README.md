# Human-recorded vowel repairs
Middle syllables selected from the dataset labelled correct (Data Benar), using the exact letter/vowel metadata, ZIP CRC, sample rate and duration. The supplied metadata MD5 did not consistently match the WAV bytes; actual file and metadata hashes are recorded separately. No synthetic isolated syllables. Fifteen recordings retain the original intro and example; three append new HeyGen-generated example words (حُوت، ذُبَاب، حَيِيَ). All eighteen contain three segments. The new examples were matched to timestamps and detected speech regions, not independently listening-reviewed.

Source: Azis, Aaz M Hafidz (2026), *Hijaiyah Letter Pronunciation Audio Dataset for Articulation Characteristic Classification*, Mendeley Data, V1, https://doi.org/10.17632/r5fy2dd98g.1.
